# 2008年（震災前）のストリートビュー地図

Google ストリートビューの撮影日一覧（タイムマシン）からは外れているものの、画像 ID を直接指定すれば今も見られる
**2008 年撮影のストリートビュー 835,590 地点** を地図にまとめたものです。

**地図: https://nao-png.github.io/sv2008-tohoku/**

点をクリックすると、その地点の 2008 年の画像を Google マップで開くリンクが表示されます。

右上の「未来へのキオクで検索した地点」をオンにすると、未来へのキオクの「震災前」表示（と同じ仕組み）で 2008 年の画像を探した 11,056 地点を表示します（緑＝2008 年の画像が見つかった 195 地点、白＝該当なし）。点をクリックすると、その場所を未来へのキオクで開くリンクが出ます。エラーで判定できなかった 87 地点も「該当なし」として表示しています（何度試してもエラーになる場所は、Google 側のデータが壊れていて「Unrecoverable data loss or corruption」と返ってきます）。

## 背景

- 日本のストリートビューは 2008 年に公開されましたが、カメラ位置が高い（2.45m）ことがプライバシー面で問題となり、
  2009 年以降カメラを下げて撮り直され、2008 年の画像は非公開になりました。
- 2011 年 12 月、Google は東日本大震災の被災地のデジタルアーカイブ「未来へのキオク」で、震災前後のストリートビューを
  特別に見比べられるようにしました（[Google ブログ](https://blog.google/intl/ja-jp/products/explore-get-answers/2011_12_blog-post_13/)）。
  ここで「震災前」として使われたのが、この 2008 年の画像です。
- Web Archive に残る「未来へのキオク」の「震災前」URL 69 件のうち 68 件がこのデータに含まれ、残る 1 件（岩手県沿岸）は
  2012 年の画像を指していました。
- 2008 年の画像どうしはリンクでつながっているため、1 枚から順にたどることで一帯を集めました。
  2008 年以外の画像へのリンクはなく、関東など他地域の 2008 年の画像は削除済みでした。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 地図（Leaflet、背景は国土地理院タイル） |

## 注意

- 収集には Google の非公開 API（[streetlevel](https://github.com/sk-zk/streetlevel) 経由）を使っています。
  仕様変更により、画像やリンクが見られなくなる可能性があります。
- 画像そのものは含まれていません。画像の著作権は Google に帰属します。
- 地図の背景は[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)の地理院タイルを使用しています。
  宮城県の県境データ（`scripts/miyagi.json`）は © OpenStreetMap contributors（ODbL）です。
