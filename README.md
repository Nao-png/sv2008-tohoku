# 2008年（震災前）のストリートビュー地図

Google ストリートビューの撮影日一覧（タイムマシン）からは外れているものの、画像 ID を直接指定すれば今も見られる
**2008 年撮影のストリートビュー 817,103 地点** を地図にまとめたものです。

**地図: https://nao-png.github.io/sv2008-tohoku/**

点をクリックすると、**2008 年と現在のストリートビューを並べて表示**します（今昔比較）。
「↺ 90°」「反対向き」「↻ 90°」で両方の向きを同時に変えられます。Google Maps の API キーを設定すると、片方を操作したときにもう片方が連動します（下記）。表示中の地点は URL（`#画像ID,向き`）に入るので、そのまま共有できます。

画像は Google マップの埋め込み表示を使っています。2008 年側は画像 ID で表示します。
現在側は、各地点から 30m 以内にある Google の撮影車による最新の道路画像を事前に調べておき、その画像 ID で表示します
（地下街・屋内や、一般の投稿写真が表示されないようにするため）。817,103 地点のうち 805,085 地点（98.5%）で見つかりました。

## 視点の連動（API キーの設定）

`config.js` に Google Maps JavaScript API のキーを書くと、2008 年と現在の画像が連動します。

- 向き・上下・ズーム: どちらを操作しても、もう片方が同じ向きになります。
- 移動: 2008 年側で道を進むと、現在側も近くの最新の画像に移ります。現在側で進むと、30m 以内に 2008 年の画像があれば 2008 年側もついてきます。

キーが空、または無効な場合は、連動しない Google マップの埋め込み表示になります。

設定手順:
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作り、請求先アカウントを設定する
2. 「Maps JavaScript API」を有効にして API キーを作成する
3. キーの制限で「HTTP リファラー」を `https://nao-png.github.io/*` に、「API の制限」を Maps JavaScript API に限定する
4. 使いすぎを防ぐため、割り当て（Quotas）で 1 日あたりの上限を設定する
5. `config.js` の `window.GMAPS_KEY = '';` の `''` の中にキーを書いて push する

無料枠を超えると料金がかかります。料金は [Google Maps Platform の料金ページ](https://developers.google.com/maps/billing-and-pricing/pricing) で確認してください。

## 背景

- 日本のストリートビューは 2008 年に公開されましたが、カメラ位置が高い（2.45m）ことがプライバシー面で問題となり、
  2009 年以降カメラを下げて撮り直され、2008 年の画像は非公開になりました。
- 2011 年 12 月、Google は東日本大震災の被災地のデジタルアーカイブ「未来へのキオク」で、震災前後のストリートビューを
  特別に見比べられるようにしました（[Google ブログ](https://blog.google/intl/ja-jp/products/explore-get-answers/2011_12_blog-post_13/)）。
  ここで「震災前」として使われたのが、この 2008 年の画像です。
- Web Archive に残る「未来へのキオク」の「震災前」URL 69 件のうち 68 件がこのデータに含まれ、残る 1 件（岩手県沿岸）は
  2012 年の画像を指していました。
- 2008 年の画像どうしはリンクでつながっているため、1 枚から順にたどることで一帯を集めました。
  2008 年以外の画像へのリンクはなく、関東など他地域の 2008 年の画像は削除済みでした。

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 地図と今昔比較ビューア（Leaflet、背景は国土地理院タイル） |
| `config.js` | Google Maps API キー（任意。設定すると視点が連動する） |
| `now/` | 各地点に対応する現在の画像 ID（地域ごとの JSON。地点をクリックしたときに読み込む） |
| `sv2008_panoids.zip` | 全地点の画像 ID・緯度・経度・撮影年月・Google マップの URL（CSV） |
| `scripts/` | 収集・地図作成に使ったスクリプトと生データ（詳細は [scripts/README.md](scripts/README.md)） |

## 注意

- 収集には Google の非公開 API（[streetlevel](https://github.com/sk-zk/streetlevel) 経由）を使っています。
  仕様変更により、画像やリンクが見られなくなる可能性があります。
- 画像そのものは含まれていません。画像の著作権は Google に帰属します。
- 地図の背景は[国土地理院](https://maps.gsi.go.jp/development/ichiran.html)の地理院タイルを使用しています。
  宮城県の県境データ（`scripts/miyagi.json`）は © OpenStreetMap contributors（ODbL）です。
